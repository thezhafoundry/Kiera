WhatsApp Desktop setup

  1. Install VB-CABLE, then reopen this page in Chrome or Edge.
  2. Select CABLE Input as the converted output above.
  3. In WhatsApp Desktop, set Microphone to CABLE Output; keep its speaker set to your headphones.
  4. Start relay before your call. Leave the output on default for testing — you'll hear the converted voice through your headphones.
